# CDM as the canonical data layer

CDM is the canonical representation of agreement terms, eligibility and margin calls exchanged between off-chain
systems and on-chain execution. Basis: the GDF/ISDA sandbox used the CDM to define agreement terms so that margin calls
fed directly into DLT actions; ISDA and GDF ask regulators to support the CDM for cross-platform consistency.
