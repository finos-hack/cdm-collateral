## Maintainer

**The constraint that forces a decision:** a GitHub Actions push job is ephemeral and headless. It runs on a throwaway `ubuntu-latest` machine with no human and no browser, and it tears everything down when the job ends (the current workflow does `docker compose down -v` at the end). So a push-triggered GitHub job cannot hand you a running console to click — whatever it starts dies at job end. That means "start on push, then click the UI" only works if the thing started on push is a **persistent, reachable environment**, not a GitHub test job.
