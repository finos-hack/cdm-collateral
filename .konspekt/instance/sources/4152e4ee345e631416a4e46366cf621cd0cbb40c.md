## Maintainer

Settlement netting (row 6): which movements should net into one transfer? CDM 7.7.0 has the elections, but no
function applies them. The elections are `CollateralInterestHandlingParameters.netInterestWithMarginCalls` and
`InterestAmountApplication`. In every option, initial margin stays out of netting because it's segregated in
escrow, and only cash in one token between one pair on one day nets.

- VM, return, interest (Recommended): Agreed VM calls, VM returns and stated Interest Amounts that fall due on one
  day net into one transfer. This matches the matrix note ('several movements fall on one day') and the ordering
  note ('several calls settling together'). Interest takes part only when netInterestWithMarginCalls is true. This
  needs a batch-settle contract function and a new cdm-ext netting function.
- Interest with VM only: Only an Interest Amount nets against a VM Delivery or Return Amount due the same day, under
  netInterestWithMarginCalls. This is smaller and follows the CDM election exactly. Two VM movements between the
  same pair don't net.
- SME first: Record the scope as an SME question and wait before building row 6. Row 7 (allocation) could start in
  the meantime.
