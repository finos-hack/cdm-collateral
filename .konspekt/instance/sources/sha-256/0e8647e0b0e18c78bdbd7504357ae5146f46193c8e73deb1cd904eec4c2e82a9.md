   - Request, decide, settle: Three separate on-chain steps with stored states, as in CollateralControl's flow-substitution. More contract code and one more transaction, with the decision recorded apart from the settlement.
2. For task-repo-substitution, CDM has no eligibility or value check. What must the substitute securities satisfy? (Any answer goes to the SME ledger as an assumption.)
   - At least equal value (Recommended): Any security with a price on the feed, other than the current one. Its quantity is the current securities' Market Value divided by its feed price, rounded up to whole units. The Buyer's agreement is the eligibility check, and the agreeing service rebuilds the event from the feed.
   - Value from Margin Ratio: Substitute quantity = Purchase Price x Margin Ratio / feed price, as in an adjustment. This also resets any margin drift at the substitution.
   - Buyer's agreement only: The Seller states any security and quantity. The service makes no value check, and the Buyer decides whether to agree.
3. For task-repo-substitution, which securities does one substitution cover? The reprice and adjustment rows cover every open repo of the pair.
   - One chosen repo (Recommended): The Seller picks one purchased repo and replaces all of its securities. The request is about specific securities, so it applies per repo. One CDM event and one on-chain settlement.
   - Every open repo: Same as the reprice and adjustment: every purchased repo where the party is Seller moves to the same substitute. One event and settlement per repo, not atomic as a group.
4. For task-repo-substitution, CDM's replacement trade starts on the substitution date with the same Purchase Price, so its accrual would restart. How should the Price Differential accrued before that date be handled? (Any answer goes to the SME ledger as an assumption.)

   - Settled in cash: Same as the adjustment: the Seller pays the Buyer the accrued Price Differential in the substitution's transaction. Reuses existing code, and it adds a cash payment to a securities swap.
