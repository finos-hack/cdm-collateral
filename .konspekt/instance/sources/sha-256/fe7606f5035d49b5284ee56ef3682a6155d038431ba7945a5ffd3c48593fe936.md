## Maintainer

Canton keeps immutability and shared logic among a deal's own parties: each stakeholder holds its own copy checked
against a shared root hash, but there is no copy held outside the deal, and history can be pruned. Paladin writes each
step's commitment to the shared Besu chain, which every validator copies.
